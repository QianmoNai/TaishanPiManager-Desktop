# TaishanPiManager Desktop

泰山派设备管理工具。本仓库按本地保存的版本快照重建 Git 历史。

当前快照：**v2.2**，来源目录：`TaishanPiManager-Desktop-v2.2`。

每个快照对应一个提交及标签；提交时间是导入时间，不代表原始开发时间。`desktop-initial` 保留早期未编号的桌面目录（其界面已标注 v2.1），`v2.1` 保留后续独立目录。

源码位于 `source/`，插件位于 `plugins/`；使用、构建方法及依赖版本见 [使用说明](使用说明.md)，第三方许可及源码见 `licenses/`、`third-party-source/` 和第三方组件说明。插件所需 Mihomo 压缩包随对应版本保留。

仓库未收录主程序 EXE、构建缓存、运行记录和界面截图。运行及分发时需自行准备 Android Platform Tools 到 `adb/`；涉及测速的版本还需按第三方组件说明准备 `iperf3/` 运行时。
