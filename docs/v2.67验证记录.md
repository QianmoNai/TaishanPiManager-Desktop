# v2.67 独立 ADB 端口

日期：2026-09-25。修改前创建 v2.67 基线标签。本地提交、构建，未推送或发布。

## 变更范围

所有调用通过统一参数构造函数显式添加 `-H 127.0.0.1 -P 5038`。覆盖普通命令、扫描、网络连接、文件传输、插件命令，以及终端、终端尺寸同步、摄像头、串口和 LD06 的 QProcess 数据流。

不自动重启默认 5037 服务，不结束 vivo 等其他软件，不修改开发板配置；开发板网络 ADB 端口仍可使用 5555。当前固定使用 5038，不提供端口设置或一键恢复入口。独立端口不能消除 USB 驱动层面的设备抢占。
