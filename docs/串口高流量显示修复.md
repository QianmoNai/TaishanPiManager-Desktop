# 串口高流量显示修复

修改前基线标签：v2.51。

接收显示每 100 ms 刷新一次，待显示缓存最多保留最近 8192 字节。超过容量时丢弃较早的待显示内容，在计数栏显示累计丢弃字节数；RX 总接收计数和波形解码不受此显示策略影响。

接收文本每行最多显示 256 个字符，历史最多约 65536 个字符。无换行长数据自动拆行，不可打印控制字符显示为占位符。接收视图和“保存日志”是经过处理的显示内容，不是完整原始串口数据备份。

验证：离屏 Qt 压力测试分别持续注入无换行文本和 HEX 数据，各 150 批、每批 16384 字节，验证显示历史和行长度有界、RX 计数正确及丢弃提示。连同相关桌面回归测试共 29 项通过；尚未做真实串口长时间实机测试。
