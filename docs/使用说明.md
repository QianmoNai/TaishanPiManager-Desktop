# 泰山派设备管理 · 使用说明

本文对应正式发布版 `v2.62-release`（本地打包目录为 `dist/v2.62`）。旧 `v2.62` 标签是动画改动前的基线，不是本次发布源码；旧版使用说明已移入[历史归档](history/使用说明-v2.48及以前.md)。

## 🚀 启动与连接

1. 从 [GitHub Release](https://github.com/QianmoNai/TaishanPiManager-Desktop/releases/tag/v2.62-release) 下载 Windows x64 ZIP，解压后运行 `TaishanPiManager.exe`。保留同目录的 `adb`、`iperf3` 和 `licenses` 文件夹，不要只复制 EXE。无需安装 Python，也无需额外下载源码或插件资源目录。
2. 用支持数据传输的 USB 线连接泰山派，确保设备已启用 ADB，点击“刷新设备”并选择在线设备。
3. 通过网络连接时，在“无线连接”入口使用设备的 IP 和 ADB 端口（通常为 `5555`）。电脑和设备需要网络互通，设备需要开启网络 ADB。
4. 使用左侧导航进入设备概览、文件、日志、终端、插件中心或网络设置。侧栏底部可切换浅色/深色模式。

未连接设备时可以浏览界面，但无法读取真实板端数据或执行设备操作。网络 ADB 使用设备的当前权限，不应直接暴露到不可信网络。

## 独立 ADB 服务（本地 v2.67）

新版位于 `dist/v2.67`。所有 ADB 客户端统一连接 `127.0.0.1:5038`，不共用默认 `5037`，也不会自动结束其他软件的 ADB 服务。设备扫描、文件传输、网络连接、插件命令、交互终端（含尺寸同步）、串口、雷达及摄像头数据流均使用此端口。

首次使用请退出旧版管理软件再启动新版；网络 ADB 需在新版重新连接。`5038` 是电脑端服务端口，不是开发板网络 ADB 的 `5555`，无需修改开发板配置或开放防火墙公网端口。若设备被其他手机助手占用，请先退出对应助手再刷新设备；若本机 5038 被其他程序占用，本软件不会自动终止该程序或退回 5037。

## 🔄 检查更新（Gitee）

GitHub 已发布 `v2.66-release`，含此入口；本地 `v2.67` 尚未发布。旧版 `v2.62-release` 不含此入口。

v2.66 改为侧栏简短文字提示，不弹独立窗口。失败时悬停文字可查看 HTTP 状态和 Qt 网络错误详情；不要发送私钥或访问令牌。仅允许 Gitee 同站 HTTPS 发行版 API 路径跳转，最多三次，整个检查最多 15 秒。本次为交互改动，不代表此前在线超时或 401 问题已解决。

1. 点击侧栏底部“检查更新”。无需连接开发板，检查在独立异步网络请求中进行，不占用设备操作队列。
2. 侧栏显示“正在检查更新…”，随后显示“发现新版本”“暂无更新”或简短失败原因。当前程序版本位于侧栏底部。
3. 发现新版或检查失败时，可点击“前往发布页”，由默认浏览器打开项目的 Release 页面，查看更新说明并自行下载 Windows x64 便携 ZIP。退出旧程序后解压新版，保留运行依赖；检查功能不自动下载、覆盖安装或执行文件。

只在点击时联网，不在启动时自动检查，不读取 Git/gh 登录凭据，不发送设备序列号或日志。请求包含软件版本与普通网络连接信息。网络失败、TLS 错误、Gitee 限流、404 或响应异常都显示失败，不把失败当作“已经是最新版”。可重新检查或手动打开发布页；匿名查询无法读取私有仓库。当前仅查询 Gitee，不回退 GitHub 或第三方下载源。

发布者应在 Gitee 创建非草稿、非预发布的正式 Release，使用 `v2.65`、`v2.65.1` 或 `v2.65-release` 这样的数字版本标签，并附 Windows 运行包。普通基线标签不会触发更新。版本按数字比较而非字符串排序；当前程序版本统一维护在 `source/app_updates.py` 的 `APP_VERSION` 中，发布新程序时需同步更新。

## 🖥️ 日常管理

- **设备概览**：读取当前设备的系统、CPU、内存、温度、存储和网络信息。刚连接或采样不足时，不应把占位值当作真实测量结果。
- **文件管理**：浏览板端目录、双击进入文件夹，使用上传/下载在电脑与设备间传输文件；上传同名文件前检查覆盖提示。文件和日志列表随窗口可用空间伸展。
- **系统日志**：选择日志类型、刷新，并按需导出。它是选定日志的读取视图，不是所有系统事件的永久审计归档。
- **交互终端**：选择在线设备后打开终端，新标签页会建立独立会话。Ctrl+C 中断前台命令，Ctrl+Shift+C/V 复制粘贴；多行粘贴需确认。关闭会话不保证终止自行脱离会话的板端服务。
- **网络设置**：查看网卡与路由、扫描 Wi-Fi、保存本地配置或同步到泰山派。切换 Wi-Fi 可能断开网络 ADB，首次配置建议使用 USB。保存配置不等于连接成功，请确认实际 IP 与连接状态。

涉及重启、网络改动或板端服务管理时，先核对目标设备和确认内容。只有明确可信的第三方插件免逐次执行确认，不应把这个规则套用于主程序其他操作。

## 🛠️ 硬件和网络工具

| 工具 | 使用入口与注意事项 |
| --- | --- |
| 网络流量与测速 | 在插件中心打开网络流量详情，按提示安装并启动监控；按实际目标选择局域网、公网或指定服务器测速，测速会消耗带宽和流量 |
| 网络代理 | 在详情页安装核心、导入配置并启动；支持本地文件及链接导入，详见[代理指南](网络代理使用说明.md) |
| 串口助手 | 选择板端串口与正确参数后收发；高流量时显示会裁剪，保存显示日志不等于保存全部原始数据，详见[高流量说明](串口高流量显示修复.md) |
| 引脚助手 | 按排针图选择 GPIO/I²C/SPI/PWM 资源；确认电平、复用和占用情况，不要将电源或地脚当作 GPIO |
| LD06 雷达 | 安装对应板端插件后使用；默认 UART3 `/dev/ttyS3`、230400、8N1，先停止占用同一串口的其他程序 |
| 摄像头助手 | 安装对应插件、选择设备和支持的格式后预览；测试画面不代表真实摄像头正常，当前提供照片保存，不提供录像 |
| RGB 灯控制 | 通过插件中心打开内置工具，控制板载灯与预设颜色 |

工具可用性取决于板端固件、设备节点和权限，不能以桌面入口存在推断硬件已经配置完成。

## 🧩 当前插件中心

当前自带 4 款可安装板端插件（网络流量、网络代理、摄像头助手、LD06 雷达视图）和 7 项内置工具（串口助手、RGB 灯控制、引脚助手、网络设置、交互终端、文件管理、系统日志）。额外导入的第三方插件会显示为独立卡片。

- 可通过搜索和“全部 / 已安装 / 网络 / 系统 / 第三方”分类定位功能。
- 自带板端插件需要按详情页提示安装或启动；内置工具无需通过第三方 ZIP 导入。
- 第三方卡片的“已导入本机”仅表示电脑已保存插件包，不表示板端已安装或服务正在运行。
- 插件中心不是在线商店，不会自动查找、下载或升级第三方插件。

## 📦 导入第三方插件

1. 从可信开发者处获取 ZIP，先检查来源、说明和脚本内容。插件 ZIP 不需要手动解压。
2. 点击“插件中心 → 导入第三方插件包”，选择 ZIP。
3. 在“信任并导入第三方插件”提示中核对名称、版本、作者和插件 ID，确认风险后导入。作者信息由包作者填写，不等于签名认证。
4. 在第三方插件卡片点击“打开页面”或“打开操作”，按插件说明使用。

**信任后，该插件的后续操作不再逐次弹出执行确认。** 导入本身不会执行板端脚本；打开带轮询配置的页面后，会自动采集当前所选设备的状态，操作按钮则由用户点击触发。脚本使用当前 ADB Shell 权限，可能为 root，并非沙箱；只信任你审查过来源与脚本的插件。

信任仅针对该第三方插件，不会取消主程序其他操作的确认。未被记录为可信的插件，其手动操作仍需确认。

### 体验 UI 展示示例

- [下载 UI 展示插件 1.0.0](../dist/test-plugin/third-party-ui-showcase-1.0.0.zip)：在仓库文件页面点击下载/原始文件，勿下载整个仓库 ZIP。
- [查看示例源码](../examples/ui-showcase/)与[第三方插件包开发指南](第三方插件开发.md)。

导入后打开“第三方插件 UI 展示”页面。连接设备时，每 5 秒采集一次主机名、内核、运行时间、负载、内存、存储、IP、路由、温度、进程数量、时间和采集状态，共 12 张卡片；“生成设备报告”“检查网络状态”“查看系统日志摘要”按钮将结果显示在“最近输出”。缺少设备命令或权限时，部分数据可能为空或显示错误。

示例主要读取设备信息，不安装常驻服务或修改设备配置。开发自己的插件请修改唯一 ID、名称和作者，再按开发指南打包。

### 🎨 页面样式与轻量动画

第三方页面使用本体的卡片、按钮和浅色/深色主题。v2.62 中，打开页面时卡片错峰淡入；卡片值、连接状态或输出内容变化时，对应区域有轻微透明度过渡，相同内容不会反复触发。

动画由主程序提供，原有插件 ZIP 无需更改或重新导入。单次动画约 200–260 毫秒，完成后停止动画重绘，关闭页面后停止动画和轮询。当前不是数值插值或任意自定义动画，插件作者不能通过 ZIP 注入桌面 Python、Qt 控件或网页代码。

页面轮询与其他设备操作共用任务队列；主程序忙时可能跳过一次采样，不保证严格每 5 秒完成更新。插件自行在板端启动的服务不受页面关闭控制，需要作者提供停止或卸载操作。

### 更新与移除

同 ID 插件包不会静默覆盖。需要更新时，先“移除本地插件包”，再导入新版并重新确认信任。移除会归档本地包并清除其信任记录，但不会自动卸载板端程序或停止板端服务；有此需要时，先使用作者提供的清理操作。

插件包保存在当前 Windows 用户的 Qt `AppLocalDataLocation/third-party-plugins` 中，独立于 EXE 目录。更换程序版本目录一般不需要重新导入同一插件。

## 🔎 常见问题与相关文档

| 现象 | 建议检查 |
| --- | --- |
| ZIP 导入失败 | 根目录必须直接包含 `plugin.json` 和声明的 `scripts/*.sh`，不能再套一层目录或夹带截图、README；详见开发指南 |
| 示例卡片一直为 `—` | 确认已选择在线设备；连接后重新打开页面，并查看“最近输出”中的轮询错误 |
| 看不到新增动画 | 确认启动的是 `dist/v2.62` 或后续包含动画的主程序，而不是旧目录中的 EXE；相同数据不会重复触发动画 |
| 移除插件后板端服务仍在运行 | 本地移除不等于板端卸载，应按插件作者说明停止或清理 |
| 串口大量接收时显示被裁剪 | 参见[串口高流量显示修复说明](串口高流量显示修复.md)，界面不保留无限长度的接收历史 |

其他操作参考[网络代理使用说明](网络代理使用说明.md)、[第三方插件包开发指南](第三方插件开发.md)及[验证记录索引](验证记录.md)。历史实机验证描述仅对应其标注的版本，不代表本次文档更新进行了新的硬件测试。
