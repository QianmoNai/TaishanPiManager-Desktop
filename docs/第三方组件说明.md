# 第三方组件与源码获取

适用发布版：`v2.62-release`。本文区分源码仓库与精简便携 ZIP；许可范围最终以各组件随附许可证为准。

## 便携包和源码不是同一个下载项

便携包只含 EXE、`adb/`、`iperf3/` 和 `licenses/`。Python/Qt 运行组件及必要板端插件资源打包在 EXE 中；**便携 ZIP 不附完整应用源码或第三方源码归档**。

- [对应发布标签的应用源码](https://github.com/QianmoNai/TaishanPiManager-Desktop/tree/v2.62-release)
- [对应标签的第三方源码归档](https://github.com/QianmoNai/TaishanPiManager-Desktop/tree/v2.62-release/third-party-source)
- [对应标签的许可证目录](https://github.com/QianmoNai/TaishanPiManager-Desktop/tree/v2.62-release/licenses)
- [应用运行与重建步骤](运行与构建.md)

获取源码时使用 `v2.62-release`，不要误用动画改动前的 `v2.62` 基线。仓库内的[源码归档目录](../third-party-source/)与[许可证目录](../licenses/)供浏览；在下载文件页面使用原始文件下载。重新分发者需按所分发组件的实际许可履行源码提供、许可声明等义务，不能仅凭本页认定已满足全部许可要求。

## 桌面组件

| 组件 | 发布构建版本 | 用途与许可入口 |
| --- | --- | --- |
| Python | 3.13.12 | Python Software Foundation License；[对应源码](https://www.python.org/downloads/release/python-31312/) |
| PySide6 / Qt | 6.11.2 | Qt Widgets 原生界面，动态库打包；LGPL v3 / GPL 等，以模块为准，见 [LGPL](../licenses/LGPL-3.0.txt)、[GPL](../licenses/GPL-3.0.txt)及上游许可 |
| pyte | 0.8.2 | VT 终端解析器，LGPL v3；[许可证](../licenses/pyte-LICENSE.txt)、[上游源码](https://github.com/selectel/pyte) |
| wcwidth | 0.8.3 | Unicode 字符宽度计算，MIT；[许可证](../licenses/wcwidth-LICENSE.txt)、[上游源码](https://github.com/jquast/wcwidth) |
| PyYAML | 6.0.3 | 安全解析 YAML，MIT；[许可证](../licenses/PyYAML-LICENSE.txt)、[上游源码](https://github.com/yaml/pyyaml) |
| PyInstaller | 6.22.3 | 构建工具，GPL 附引导程序分发例外；[上游许可和源码](https://github.com/pyinstaller/pyinstaller) |

Qt 源码及构建资料：[Qt 官方源码仓库](https://code.qt.io/)、[Qt 开源下载说明](https://www.qt.io/download-qt-installer-oss)。PySide6 源码：[pyside-setup](https://code.qt.io/cgit/pyside/pyside-setup.git/)。重建时选择对应版本，不要默认使用上游最新分支替代发布版本。

用户可为调试 LGPL 组件的修改进行必要的逆向工程。修改 Qt/PySide6 时可从源码重建应用；单文件 EXE 在运行时解包依赖，并非在 EXE 旁放任意 Qt DLL 就保证替换生效。具体重建及替换需遵循组件 ABI 和许可要求。

## 外部运行文件与板端核心

### ADB

Android Platform Tools ADB 沿用项目已有组件，声明见 [adb/NOTICE.txt](../adb/NOTICE.txt)。发布包需要保留 ADB 及配套 DLL。

### iperf3 3.21（Windows）

使用 ar51an/iperf3-win-builds 提供的无 OpenSSL 版构建：[上游二进制来源](https://github.com/ar51an/iperf3-win-builds/releases/tag/3.21)、[许可证](../licenses/iperf3-LICENSE.txt)。

对应源码：[发布标签下的 iperf-3.21.tar.gz](https://github.com/QianmoNai/TaishanPiManager-Desktop/blob/v2.62-release/third-party-source/iperf-3.21.tar.gz)。源码位于仓库，不在便携 ZIP 中；可参考上游构建环境，在 Cygwin 中运行 `./configure && make`。

### Cygwin 3.6.7-1

iperf3 使用的独立运行时，GPL-3.0-or-later 及链接例外。见 [COPYING](../licenses/cygwin-COPYING.txt)与[例外说明](../licenses/cygwin-CYGWIN_LICENSE.txt)。

对应源码与 cygport 配置：[发布标签下的源码归档](https://github.com/QianmoNai/TaishanPiManager-Desktop/blob/v2.62-release/third-party-source/cygwin-3.6.7-1-src.tar.xz)。[上游来源](https://mirrors.kernel.org/sourceware/cygwin/src/release/cygwin/)及[构建说明](https://cygwin.com/faq/faq.html#faq.programming.building-cygwin)。运行时位于便携包的 `iperf3/`，源码归档不在便携包内。

### Mihomo v1.19.31（Linux ARM64）

GPL-3.0，使用该版本官方未修改核心，打包在主程序插件资源中。[官方项目](https://github.com/MetaCubeX/mihomo)、[许可证](../licenses/mihomo-LICENSE.txt)、[对应发布标签的源码归档](https://github.com/QianmoNai/TaishanPiManager-Desktop/blob/v2.62-release/third-party-source/mihomo-v1.19.31.tar.gz)。完整构建工程和依赖说明以对应上游版本为准。
