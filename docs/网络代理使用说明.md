# 网络代理使用说明

适用主程序：`v2.62-release`。内置核心为 Mihomo v1.19.31 Linux ARM64。旧版逐次更新与测试描述保存在[历史代理记录](history/网络代理-v2.22至v2.30.md)。

## 开始使用

1. 连接并选中泰山派，进入“插件中心 → 网络代理”。
2. 在常驻的“配置与服务管理”卡片中点击“安装 / 升级核心”。升级已有核心前先停止服务。
3. 选择“导入本地文件”，或填写完整 Clash/Mihomo 订阅配置链接并点击“从链接导入”；导入前同样先停止服务。
4. 核心校验成功后启动服务，按需选择规则、全局或直连模式。未导入有效配置不能启动。

核心随主程序离线提供，无需编译 SDK。配置与节点由用户提供，程序不附私人订阅。只接受 Clash/Mihomo YAML、JSON 配置；仅包含 Base64 节点列表的通用订阅不支持。链接下载上限 4 MB，等待超时 20 秒，支持 HTTP/HTTPS 重定向。订阅链接导入成功后清空，不保存到电脑；没有定时更新订阅功能。配置中的 provider 地址仍可能保存在板端。

文件型 provider 需提前放到设备插件目录的对应相对路径，URL provider 由核心按配置下载。校验失败保留原配置。

## 局域网访问与安全边界

HTTP/SOCKS 共用端口 `7890`，默认只监听泰山派本机 `127.0.0.1`。需要电脑或其他局域网设备使用代理时，在导入前勾选“导入时允许局域网访问”，再导入配置，然后在客户端手动设置“泰山派 IP:7890”。勾选本身不会立即改变已经导入的配置。

只在可信局域网开放；保留并检查配置中的代理认证，避免转发到公网。本功能是显式代理，不接管系统路由、TUN、透明代理或 DNS；普通程序必须主动使用代理地址。导入会关闭这些接管功能并固定代理端口。

控制接口为 `127.0.0.1:9090`，管理通过临时 ADB 转发和随机密钥进行，不直接开放到局域网。允许访问代理端口不等于允许访问管理接口。

## 节点选择与延迟测试

启动核心后选择策略组，点击节点卡片切换；蓝色边框表示当前选择。只有可手动选择的 Selector 组允许手动切换，自动选择、故障转移等由核心决定。规则模式下，是否经过所选策略组仍由配置规则决定。

- 支持名称/协议搜索，以及配置顺序、延迟、名称排序。
- 卡片“测试”只测试该节点；“测试当前组”包含被搜索隐藏的节点，不自动改变选择。
- 默认测试地址为 `https://www.gstatic.com/generate_204`，可修改。每节点超时 5 秒，每批最多 4 个并行。
- 延迟是设备经该节点访问测试地址的 HTTP 耗时，不是 ICMP ping。“不可达”不代表所有网站都无法访问。
- 取消或离开页面后不再发起下一批，当前批允许完成。REJECT/REJECT-DROP 不测速。
- 批量测试期间不会自动重排节点；需要按新延迟排序时主动选择排序选项。切换设备会清空会话测试结果。

## 网站与出口 IP

“网站测试”提供 Apple、GitHub、Google、YouTube，并支持最多 8 个自定义 HTTP/HTTPS 地址（仅本次会话保留）。请求通过 ADB 转发进入泰山派代理，不是电脑直连；HTTPS 校验证书，每次连接/读取等待超时 8 秒，最多 5 次重定向。

网站测试不运行 JavaScript，也不能证明登录或视频播放可用。403 等受限状态与连接失败、超时分别显示。

“IP 信息”经同一代理查询 HTTPS ipwho.is 服务。IP 默认隐藏，可手动刷新或每 300 秒刷新；自动刷新仅在页面可见且没有其他操作时运行。国家、位置和服务商信息来自第三方数据库，可能不准确。规则模式可能给不同网站分配不同出口，查询结果仅代表此次 IP 查询路径。切换节点、模式、设备或停止服务后需重新查询。

## 文件、日志与卸载

- 核心与配置目录：`/userdata/network-proxy`；目录权限 700，当前配置权限 600。
- 自启入口：`/etc/init.d/S96tspi-proxy`；需要时通过“开机自动启动”设置。
- 运行日志：插件目录中的 `service.log`；配置校验日志：`validation.log`。启动时轮换一份运行日志。
- 安装验证哈希、架构与脚本语法，事务失败尝试恢复原文件。
- 卸载先停止服务、移除开机入口，再归档整个插件目录到 `/userdata/proxy-backups/removed-*`，配置和日志仍在设备备份中。

本说明没有新增板端实测。历史转发测试使用直连规则，不代表私人订阅或付费节点已验证。相关记录见[验证索引](验证记录.md)；串口波形功能不属于网络代理，相关历史描述已保留在归档中。
