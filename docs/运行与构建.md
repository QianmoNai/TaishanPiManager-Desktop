# 运行与构建

适用源码标签：`v2.62-release`。建议使用 Windows 10/11 x64、Python 3.13；发布构建环境使用 Python 3.13.12。其他 Python 版本未在本指南中承诺通过验证。仅运行成品时不需要安装 Python。

## 获取源码与依赖

在 PowerShell 中执行。请使用尚不存在的克隆目标目录；若已有仓库，请在确认自己的未提交改动后自行选择工作副本，不要强制覆盖。

```powershell
git clone --branch v2.62-release https://github.com/QianmoNai/TaishanPiManager-Desktop.git TaishanPiManager-Desktop-release
cd TaishanPiManager-Desktop-release
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install PySide6==6.11.2 pyte==0.8.2 wcwidth==0.8.3 PyYAML==6.0.3
.\.venv\Scripts\python.exe source\desktop.py
```

使用虚拟环境中的 Python 完整路径，不需要修改 PowerShell 执行策略或激活脚本。PySide6 提供界面，pyte/wcwidth 提供终端解析，PyYAML 解析代理配置。当前串口工具通过 ADB 操作板端串口，不能用安装 `pyserial` 代替这些依赖。若本机没有 `py` 启动器，可用已安装 Python 3.13 的完整路径创建虚拟环境。

## 运行测试

在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s source -p "test_*.py"
```

只回归第三方插件与动画：

```powershell
Push-Location source
try {
    ..\.venv\Scripts\python.exe -m unittest test_external_plugins test_external_plugin_ui test_plugin_motion
} finally {
    Pop-Location
}
```

部分测试依赖历史示例包或工具，勿删除 `dist` 中测试所需的已有文件。自动化、离屏测试不等于 USB、网络和所有外设实机验证，验证范围见[验证记录](验证记录.md)。

## 重建精简便携包

确保根目录的 `plugins`、`adb`、`iperf3`、`licenses` 以及 `source` 资源完整。在同一 PowerShell 会话、仓库根目录执行；输出使用唯一名称，避免覆盖旧构建。

```powershell
.\.venv\Scripts\python.exe -m pip install PyInstaller==6.22.3
$buildId = 'local-' + [guid]::NewGuid().ToString('N')
$outDir = Join-Path 'dist' $buildId
$workDir = Join-Path 'build' $buildId
.\.venv\Scripts\python.exe -m PyInstaller --clean --distpath $outDir --workpath $workDir source\build_desktop.spec
if ($LASTEXITCODE -ne 0) { throw 'PyInstaller 构建失败' }
Copy-Item -LiteralPath adb,iperf3,licenses -Destination $outDir -Recurse
$appPath = (Resolve-Path (Join-Path $outDir 'TaishanPiManager.exe')).Path
$checkProcess = Start-Process -FilePath $appPath -ArgumentList '--smoke-test' -WindowStyle Hidden -PassThru
if (!$checkProcess.WaitForExit(45000)) { throw '启动自检超时，请检查该构建进程' }
$checkProcess.Refresh()
if ($checkProcess.ExitCode -ne 0) { throw '启动自检失败' }
$zipPath = Join-Path 'dist' ('TaishanPiManager-Windows-x64-' + $buildId + '.zip')
Compress-Archive -Path (Join-Path $outDir '*') -DestinationPath $zipPath
Get-FileHash -LiteralPath $zipPath -Algorithm SHA256
```

成品结构：

```text
TaishanPiManager.exe
adb/
iperf3/
licenses/
```

EXE 内嵌必要 Qt 运行组件和板端插件资源。便携 ZIP 不需要外置 `source`、`plugins`、宣传素材、历史构建或示例插件包。重新编译可能因工具链、时间戳等产生不同哈希，本指南不承诺字节级可复现。

`v2.62-release` 对应现有正式发布；不要移动这个标签去覆盖后续修改。日常仅修改文档、图片或示例插件包时不新建主程序标签；新正式发布标签按用户授权处理。Gitee 容量曾超出配额，发布 ZIP 应走发行版附件，而非再次加入 Git 历史。
