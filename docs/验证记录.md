## 尚不能据此宣称的验证

本轮没有新的真实串口长时间压力测试、全部外设回归或全部网络环境测试。没有验证任意第三方插件的安全性，也没有完成所有第三方订阅节点的真实转发测试。离屏视觉测试不代表所有 DPI、显卡驱动和 Windows 主题组合都已测试。
